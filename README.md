# adehub notebooks

Example notebooks for [adehub](https://pypi.org/project/adehub/), the Python
SDK for [ADE Hub](https://adehub.cloud). Each one opens directly in Colab.

| Notebook | What it does | |
| --- | --- | --- |
| `quickstart.ipynb` | Sign in, load a dataset into pandas, query it with SQL, push a result back | [![Open in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/adehub-cloud/notebooks/blob/main/quickstart.ipynb) |
| `publish.ipynb` | Publish a DataFrame as a new dataset or a new version | [![Open in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/adehub-cloud/notebooks/blob/main/publish.ipynb) |

Install the SDK anywhere with `pip install "adehub[data]"`. Documentation:
https://adehub.cloud/docs.
